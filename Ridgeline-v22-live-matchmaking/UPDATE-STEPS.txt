RIDGELINE SEASON v22 — LIVE MATCHMAKING UPDATE
==============================================

WHAT THIS FIXES
- PLAY in Arena or Squad now searches for live players: it puts you in the match
  that already has the most real people in it (with space and time left).
- The first person in gets a 20-second search window. Anyone who joins during
  the countdown gets at least 8 seconds to get ready.
- The countdown screen says "Searching for live hunters…" or "2 live hunters in
  this match", and how many people are online right now.
- Bots never take a real player's spot. A full room no longer says
  "Room is full": the 9th person goes into a second match automatically.
- The lobby counts everyone who has the game open (not just people in a match),
  and the Arena/Squad cards show how many are in matches right now.
- Two guests with the same name now show up as Hunter and Hunter2.
- Accounts, stats and leaderboards are untouched. Nothing resets.

There are only 2 files. They must go up TOGETHER (the page checks that the
server is the same version).

STEP 1 — Unzip
1. On your Windows PC, find "Ridgeline-v22-live-matchmaking.zip" in Downloads.
2. Right-click it → "Extract All…" → Extract.
   You get: index.html, a folder called "server" with server.js inside, and this file.

STEP 2 — Upload the game page (index.html)
1. Go to https://github.com/moonvisions/ridgeline-season and sign in.
2. Make sure you are on the main page of the repo (you see the file list).
3. Click "Add file" (top right of the file list) → "Upload files".
4. Drag index.html from the unzipped folder onto the page.
5. Scroll down, type "v22 live matchmaking" in the box, leave "Commit directly
   to the main branch" selected, click the green "Commit changes".

STEP 3 — Upload the server (server/server.js)
1. Back on the repo page, click the "server" folder.
2. Click "Add file" → "Upload files".
3. Drag server.js from the unzipped "server" folder onto the page.
   (Make sure you are INSIDE the server folder — the address bar ends in /server.)
4. Type "v22 server" and click "Commit changes".

STEP 4 — Let DigitalOcean deploy it
1. Go to https://cloud.digitalocean.com → Apps → your Ridgeline app.
2. A new deployment should start by itself within a minute (Activity tab shows
   "Building" then "Deployed"). It takes about 3–5 minutes.
3. If nothing starts after 2 minutes: click "Actions" (or "Create Deployment")
   → "Deploy". Nothing in Settings needs to change — your secrets stay as they are.

STEP 5 — Check it is live
1. On your phone, open:  https://www.ridgelineseason.com/api/status
2. You should see  "build":"arena-v22"  and a "live" section like
   "live":{"online":1,"inMatch":0,...}
   If it still says arena-v21, wait 2 more minutes and refresh.
3. Open ridgelineseason.com, pull down to refresh (or close and reopen the tab).
   At the top of the lobby it should say "Server online · build arena-v22".

STEP 6 — Test with two devices (2 minutes)
1. Phone: open the game → Arena → PLAY. You see "Searching for live hunters…".
2. Within 20 seconds, on your computer (or a friend's phone): open the game →
   Arena → PLAY.
3. Both screens should say "2 live hunters in this match", and each of you shows
   up in the other's scoreboard (top left). The other bots are Dale, Marisol,
   Otis and so on.
4. Same test works for Squad.

IF SOMETHING LOOKS WRONG
- The lobby says "server is running arena-v21 but this page is arena-v22":
  the server upload didn't deploy yet. Repeat Step 3/4.
- The opposite message (server v22, page v21): refresh the page; your browser
  kept the old one.
- Admin page (your ADMIN_KEY): https://www.ridgelineseason.com/admin — the rooms
  list now shows each match, how many live players are in it, and which
  players are bots.
